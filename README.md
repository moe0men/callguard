# CallGuard

Определитель спам-звонков для Android. Незнакомый номер проверяется по данным определителя номера Яндекса: если номер помечен как спам, мошенничество или телемаркетинг, звонок остаётся, но звонит без звука. Всё остальное звонит как обычно.

Никаких локальных баз, аккаунтов и API-ключей. Один универсальный APK на все устройства.

## Возможности

- Проверка входящего до гудка через `CallScreeningService`.
- Номера из контактов не проверяются.
- Спам: `setSilenceCall(true)`, без блокировки и сброса.
- Нет данных, таймаут или ошибка сети — обычный звонок.
- Кэш вердиктов в памяти: 6 часов для спама и «чисто», 15 минут для «нет данных».
- Тёмная и светлая темы, Material 3.

## Как работает

1. Приложение получает роль `ROLE_CALL_SCREENING`.
2. Входящий номер не из контактов → запрос:

```
GET https://cid.yandex.net/v7/info?phonenums=79001234567&verticals=ugc&lang=ru&lr=213
Authorization: Bearer android
```

3. Разбор полей `ugc.verdict`, `ugc.polarity`, `ugc.description`, `geo.results[0].name`:

| Ответ | Вердикт | Поведение |
|---|---|---|
| `polarity: "negative"` или `verdict` содержит `telemarketing`, `spam`, `fraud`, `debt`, `collect`, `advert`, `promo` | SPAM | беззвучно |
| `polarity: "positive"`, `notification`, `bank.notification`, `taxi`, `telecom` | CLEAN | обычный звонок |
| `verdict: null`, нет `ugc` | UNKNOWN | обычный звонок |

4. Ответ приходит за 70–150 мс, дедлайн 2.5 с. Android ждёт ответ `respondToCall` не больше 5 с.

## Установка

1. Скачать `CallGuard-1.0.0.apk` со страницы https://github.com/moe0men/callguard/releases/latest
2. Разрешить установку из неизвестных источников и установить.
3. Открыть приложение, нажать «Выдать» у роли определителя номера, затем «Разрешить» у доступа к контактам.

## Сборка

Нужен JDK 17 и Android SDK 36.

```bash
./gradlew assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`. Сборка подписана debug-ключом, поэтому ставится на любой телефон без своих ключей.

## Ограничения

- Неофициальный API Яндекса: может измениться без предупреждения.
- Метки Яндекса — отзывы пользователей, не приговор. Ложные срабатывания возможны.
- Проверка должна уложиться в 2.5 с.
- Некоторые прошивки (Xiaomi, Samsung, Huawei) душат фоновые сервисы: нужен автозапуск и отключение оптимизации батареи.
- В Google Play такое приложение не опубликуют: политика запрещает перехват звонков сторонними приложениями.
- Номер передаётся на серверы Яндекса.
